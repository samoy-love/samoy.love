## Проблема

Ручная установка игр и модпаков из архивов — боль: при каждом обновлении приходится перекачивать гигабайты, вручную заменять файлы и молиться, что старые «хвосты» ничего не сломают.

## Решение

ChillHub — лаунчер для Windows 10–11 с серверной частью на Go. Обновления ставятся **как дифф**: скачиваются только изменившиеся файлы, а конечная папка игры становится точной копией серверной версии — лишнее удаляется, пустые каталоги создаются по манифесту.

## Как устроено

- **Public API** отдаёт список игр, версии, манифесты и новости (JSON + статика за nginx).
- **Admin API + веб-админка**: загрузил ZIP-сборку — версия и `latest` опубликованы мгновенно.
- **Надёжные докачки**: HTTP Range, возобновление `.part`-файлов, многопоточная загрузка.
- **Контроль целостности**: хеши Blake3 / SHA-256 на каждый файл.
- **Новости в клиенте**: Markdown + изображения, чтобы патчноуты жили рядом с кнопкой «Играть».

## Стек

Go, nginx, systemd, WPF-клиент, Blake3/SHA-256, Makefile-автодеплой на Ubuntu.
